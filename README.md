# KeeperSage
KeeperSage is a self-developed extensible knowledge platform, built for managing private domain knowledge assets and providing business-oriented decision support.

Keeper represents the custodian of knowledge assets, Sage stands for domain wisdom and advisory capability.

The platform is not limited to RAG retrieval-augmented generation. Reserved extension capabilities include AI Agent, multi-modal parsing and business automation workflows.

## ✨ Features
- Private knowledge asset management
- Modular RAG pipeline
- Extensible plugin architecture for agent & workflow
- Lightweight self-hosted deployment
